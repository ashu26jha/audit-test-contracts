# Select Contracts

After selecting your repository and branch, the next step is to select the contracts that you want to get audited.

You can simply select the contracts from the list displayed. Alternatively, you can also search for them using the search bar.

Click on "Next" button to proceed to the final step.

![Select Contracts](/img/select_contracts.png)

:::info Subscription Limits

### Free Subscription

- 500 lines of code
- 3 contracts per scan

### Professional Subscription

- 2000 lines of code
- 10 contracts per scan

### Enterprise Subscription

- 8000 lines of code
- 50 contracts per scan
  :::
