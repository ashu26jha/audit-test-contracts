# Select Repository

On the top right of the dashboard, click the 'Scan Code' button. You will be redirected to the select repository page.

![Scan Code](/img/click_scan_code.png)

Choose the Github organization and the repository that you want to audit, then click on "Next"

![Select Repository](/img/select_repo_1.png)

:::info
If you don't see your repository listed, you can click on the `Add repo from GitHub` button to manage the repositories AuditAgent has access to.
:::

## Enter repository URL (Optional)

You can also enter any public GitHub repository URL.
